# Awesome Opus 5.5 Videos

Files here are copied from https://github.com/yihui-dev/awesome-opus5-5-videos (repository licence: MIT). This wrapper was written in this repository; it is not part of upstream.

- `README.md`: the categorised index. Start here, or grep it for a topic.
- `prompts/<author>-<id>.md`: one video each: title, category, author, link to the original post, and the prompt.
- `data/videos.json`: the same list as data, for filtering by category or author.

Each prompt was written by the creator named in its file. Adapt a prompt to the user's subject instead of reusing it word for word, and name the original author when a result follows one closely.
